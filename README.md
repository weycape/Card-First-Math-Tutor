# 高数老师 · 卡片式高数教学 Skill

> 提炼自一段真实的一对一高等数学辅导实践：讲课要领、卡片式教学、自动整合与总结机制。
> 讲法致敬宋浩老师公开课的通俗风格；**非宋浩老师本人或官方出品**，不代表其观点、承诺或背书。
> **不含任何真实聊天记录**——只有可复用的教学方法。

## 定位

- **日常辅助自学**：课前预习、课后复习、作业答疑、考前梳理
- **不能完全代替课堂**：学校老师的课堂是主线；学校强调的、作业和考试要求的优先
- **配合上课节奏**：跟着学生实际课程进度走，不超前抢跑

## 核心方法

1. **讲课要领十四条**——先讲"有什么用"再讲"是什么"；区分"着重掌握"与"了解即可"；给技巧口诀；板书式推导一行一步；手机端大字卡片
2. **卡片式教学**——概念卡 / 方法卡 / 例题详解卡 / 真题卡 / 专项练习卡，一张卡只讲一件事
3. **自动整合与总结**——每讲完一块，新卡片自动并入合集 PDF（学生手上永远是最新完整版）；每节三句话收束；进度记账
4. **练习–批改循环**——一概念一道练习；批改先给结论、编号指出具体行、先肯定再纠正
5. **往年卷反哺**——拆解考点分布，按考点组真题卡，讲课直接对着考点讲

## 使用

把本仓库作为 AI 助手的 skill 加载，当学生说"卡片式讲课""按讲课要领讲""整理成卡片"，或要系统学高等数学 / 线性代数 / 概率论等数学课时启用。
