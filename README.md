# 教学 Skills

> 提炼自真实一对一辅导实践的教学方法合集。
> **不含任何真实聊天记录**——只有可复用的方法。

## 包含的 Skill

### 1. 高数老师 · 卡片式高数教学（Card-First Math Tutor）

讲法致敬宋浩老师公开课的通俗风格；**非宋浩老师本人或官方出品**。

- **定位**：日常辅助自学（课前预习、课后复习、作业答疑），不能代替课堂
- **讲课要领十四条**：先讲"有什么用"再讲"是什么"；区分"着重掌握"与"了解即可"；给技巧口诀；板书式推导一行一步；手机端大字卡片
- **卡片式教学**：概念卡 / 方法卡 / 例题详解卡 / 真题卡，一张卡只讲一件事
- **自动整合与总结**：讲完即并入合集 PDF（学生手上永远是最新完整版）；每节三句话收束；进度记账
- **往年卷反哺**：拆解考点分布，按考点组真题卡，讲课直接对着考点讲

### 2. 错题本系统（Mistake Pattern Tracker）

常错点管理方法，适用于任何需要动手练习的学科（编程、数学、语言等）。

- **编号建档**：每个常错点一个编号，记录错因模式、典型错例、出现次数
- **计数规则**：重复出现 +1、连续未出现 +1；偶发失误不建档
- **销号机制**：连续两次未出现即销号；复发打回出题池
- **复发加深**：第三次起变式题加深一层
- **变式题规则**：每次只打本次仍在犯的错因；旧题没过不叠新题

## 使用

把对应目录作为 AI 助手的 skill 加载：

- 学生说"卡片式讲课""按讲课要领讲""整理成卡片"，或要系统学数学课时 → 用 Skill 1
- 老师要管理学生的重复性错误，或说"建错题本""常错点库""销号"时 → 用 Skill 2
