# 进度模板

> 有文件/记忆能力时按此模板记账；没有时，每节末尾把同样内容以文字版小结发给学生自己存。
> 学生问"上次学到哪儿"时，直接按此模板回答。

```text
第 X 章 · 第 X 节（节名）
日期：XXXX-XX-XX

已讲：
- 要点1（一句话）
- 要点2（一句话）
- 要点3（一句话）

练习状态：
- 练习1：已交 ✅ / 未交 ⏳（批改结论：通过 / 待改）
- 练习2：已交 ✅ / 未交 ⏳

待交事项：
- （如：1/(x+3) 间断点分类）
- （如：用定义求 f(x)=x³ 在 x=1 处的导数）

合集：第 N 页（最新完整版）
```

## 记账规则

- 每讲完一节更新一次，不攒着。
- "已讲"只记结论，不记推导过程（过程在卡片里）。
- 待交事项只增不减，做完一项勾掉一项；不要口头说"下次再说"。
- 跨对话时，开场先报进度模板，再问"继续还是先清待交？"
